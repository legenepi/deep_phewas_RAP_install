# Overview
These scripts install and run [DeepPheWAS](https://github.com/Richard-Packer/DeepPheWAS) on the [UK Biobank Research Analysis Platform (RAP)](https://www.ukbiobank.ac.uk/enable-your-research/research-analysis-platform).

## Requirements

* A UK Biobank RAP project

# Installing DeepPheWAS in your RAP project

1. Log into the [UK Biobank RAP web interface](https://ukbiobank.dnanexus.com/) 
2. Start a JupyterLab instance from the Tools menu
3. Open a Terminal
4. Clone this repository
```
git clone https://github.com/legenepi/deep_phewas_RAP_install.git
```
## Phenotype generation and running regenie step 1

In JupyterLab, from the `deep_phewas_RAP_install` directory open the Jupyter Notebook
```
deep_phewas_step1.ipynb
```
and follow the instructions and run the code chunks.
